# 💬 Chat Online

### 👋 Привет!

Это мое мини-приложение — **супер простой онлайн-чат**, сделанный с душой 💻❤️

---

### ✨ Функционал

🔹 Просмотр списка доступных чатов (комнат)  
🔹 Создание собственной комнаты  
🔹 Вход в существующую комнату  
🔹 Просмотр сообщений участников  
🔹 Отправка своих сообщений в режиме реального времени 🚀

---

## 🚀 Запуск приложения

### 1️⃣ Создание и активация виртуального окружения:

```bash
python -m venv venv
.\venv\scripts\activate       # 👉 Windows
source venv/scripts/activate  # 👉 Linux / macOS
```

### 2️⃣ Установка зависимостей:

```bash
pip install -r requirements.txt
```

### 3️⃣ Запуск сервера:

```bash
uvicorn index:app --reload --host 0.0.0.0 --port 8000
```

🌐 После этого приложение будет доступно по адресу:  
`http://localhost:8000` или по IP вашего устройства в локальной сети 📱💻

---

## 🛠️ О проекте: почему и как он был создан?

Я создал это приложение, потому что давно хотел реализовать **взаимодействие клиента с сервером в реальном времени**.  
💡 В качестве технологии для этого я выбрал **Long Polling** — простой, но эффективный способ поддерживать постоянную связь между фронтендом и бэкендом.

## 🧩 Технологический стек

🔸 **Frontend**:  
Обычные `HTML` и `CSS`, но с использованием **TypeScript** — для типизации, удобства разработки и большей надежности.

🔸 **Backend**:  
Разработан с использованием **FastAPI** — современного, асинхронного фреймворка для создания веб-приложений на Python 🐍⚡
